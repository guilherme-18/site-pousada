# sobre o site da *pousada*

O site da **pousada**, utilizando o **Malai Hotel** como exemplo, é um projeto desenvolvido para apresentar informações sobre um hotel, destacando suas principais características, como:

- **Acomodações**
- **Atrações**
- **Áreas de lazer**
- **Gastronomia**
- **Experiências oferecidas aos visitantes**

O site possui páginas como:

- **Home**
- **Quartos**
- **Atrações**
- **Contatos**
- **Avaliações**

Além disso, utiliza imagens e elementos visuais para tornar a navegação mais agradável, organizada e atrativa para os visitantes.

### objetivo

O projeto foi desenvolvido como parte de um trabalho escolar do curso de *Análise e Desenvolvimento de Sistemas (ADS)*, com o objetivo de aplicar os conhecimentos adquiridos durante o curso na criação e estilização de um site.

Atualmente, o **site ainda está incompleto**, e futuramente poderão ser adicionadas novas páginas, funcionalidades, melhorias visuais e outros conteúdos. É importante destacar que este é apenas um projeto acadêmico, desenvolvido para fins educacionais, e não um site comercial finalizado.

O desenvolvimento utiliza apenas **HTML e CSS puro**, sem JavaScript e sem banco de dados. Dessa forma, o projeto tem como foco a estruturação das páginas, a estilização dos elementos, a organização das informações e a aplicação dos fundamentos do desenvolvimento web.
